# BookMyShow — MERN Movie Ticket Booking Platform

A full-stack movie ticket booking platform built with MongoDB, Express, React and Node.js
as the applied capstone project for the Scaler Neovarsity – Woolf MSc in Computer Science.

> Work in progress — see commit history for incremental development.

## Repository layout

```
bookmyshow/
├── server/   Express + Mongoose REST API, Socket.IO, Razorpay, email
└── client/   React + Vite SPA (Redux Toolkit, Ant Design)
```
